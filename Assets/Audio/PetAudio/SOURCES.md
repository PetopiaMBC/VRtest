# 실제 강아지 음원 출처

`Resources/PetAudio` 폴더의 강아지 목소리는 파형으로 만든 기계음이 아니라 실제 강아지 녹음을 짧게 잘라 만든 음원입니다.

## 사용한 원본

| 원본 파일 | 사용하는 소리 | 라이선스 |
| --- | --- | --- |
| `bark_bigsoundbank_sleddog_2954.mp3` | `Bark_01~04` | CC0 1.0 |
| `pant_freesound_blukotek_424948.mp3` | `PantCycle`, `Pant_In`, `Pant_Out`, `Sniff` | CC0 1.0 |
| `dog_whimper.mp3` | `HappyWhine_01~03` | CC0 1.0 |
| `dog_bark_small.mp3`, `dog_bark_large.mp3`, `dog_panting.mp3` | 비교·향후 교체용 원본 | CC0 1.0 |
| `dog_growl_play.mp3` | 향후 놀이 으르렁 소리용 원본 | CC0 1.0 |

- 배포처: Pet Decoder Audio Test Fixtures
- 원출처: Red Library Sound Effects Collection, Craig Smith(USC)
- 라이선스: CC0 1.0 Universal / Public Domain
- 배포 페이지: https://huggingface.co/datasets/petdecoder/pet-decoder-audio-fixtures
- 원출처 페이지: https://archive.org/details/Red_Library_Animals_Dogs

CC0 음원이므로 상업·비상업 프로젝트에서 사용하거나 수정하고 재배포할 수 있으며, 이름 표시 의무는 없습니다. 그래도 나중에 출처를 잊지 않도록 이 문서를 함께 보관합니다.

## 다시 만드는 방법

1. Unity 위쪽 메뉴에서 `Tools`를 누릅니다.
2. `My Little Pet`을 누릅니다.
3. `실제 강아지 음원 다시 만들기`를 누릅니다.
4. 긴 원본 녹음에서 게임용 짧은 모노 WAV 17개가 다시 만들어집니다.

원본 파일은 `Assets/Audio/PetAudio/SourceRecordings`에 보관됩니다.

## 선택용 후보 음원 출처

아래 녹음은 `Assets/Audio/PetAudio/Audition`의 비교용 후보를 만드는 데 사용했습니다. 후보는 아직 게임에서 재생되지 않습니다.

- OpenGameArt `Dog barking mono`: https://opengameart.org/content/dog-barking-mono
- BigSoundBank `Barking Dog #2`: https://bigsoundbank.com/barking-dog-2-s2954.html
- BigSoundBank `Barking Dogs`: https://bigsoundbank.com/barking-dogs-s0288.html
- BigSoundBank `Dogs Breathing`: https://bigsoundbank.com/dogs-breathing-s1547.html
- Freesound `a small dog is barking.wav`: https://freesound.org/people/blukotek/sounds/424958/
- Freesound `the dog is panting.wav`: https://freesound.org/people/blukotek/sounds/424948/
- Freesound `bark yelp dog small int.flac`: https://freesound.org/s/452180/
- Freesound 프렌치불도그 호흡 녹음: https://freesound.org/people/felix.blume/sounds/134820/
- Freesound 쉬는 강아지 호흡 녹음: https://freesound.org/people/schwappo/sounds/448784/

각 출처 페이지에서 CC0 라이선스를 다시 확인했으며, 프로젝트에는 출처 추적을 위해 원본 또는 공개 미리듣기 파일을 함께 보관합니다.
