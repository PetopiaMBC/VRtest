# My Little Pet 음향 사용 설명서

이 문서는 Unity를 처음 만지는 사람도 강아지 소리를 확인하고 고칠 수 있도록 만든 설명서입니다.

어려운 코드를 몰라도 괜찮습니다. 먼저 아래의 **가장 쉬운 확인 방법**만 따라 하면 됩니다.

---

## 1. 지금 들어 있는 소리

강아지 소리는 모두 이 폴더에 있습니다.

`Assets/Audio/PetAudio/Resources/PetAudio`

| 파일 이름 | 어떤 소리인가요? | 언제 사용하나요? |
| --- | --- | --- |
| `Paw_Hard_01~06` | 딱딱한 바닥을 밟는 발소리 | 나무, 타일, 콘크리트, 일반 바닥 |
| `Paw_Soft_01~06` | 푹신한 곳을 밟는 발소리 | 카펫, 러그, 잔디, 침대 |
| `PantCycle_01~04` | 실제 호흡이 이어지는 자연스러운 헥헥거림 | 자동 헥헥거림 |
| `Pant_In_01~03` | 헥헥거릴 때 숨을 들이마시는 소리 | 달린 뒤, 안겨 있을 때, 쓰다듬을 때 |
| `Pant_Out_01~04` | 헥헥거릴 때 숨을 내쉬는 소리 | 들숨과 번갈아 재생 |
| `Bark_01~04` | 짧게 멍멍 짖는 소리 | 플레이어가 강아지를 부를 때 |
| `HappyWhine_01~03` | 기분 좋은 낑낑거림 | 쓰다듬기를 시작했을 때 |
| `Sniff_01~03` | 킁킁 냄새 맡는 소리 | 탐색이나 특별한 Idle 애니메이션 |
| `BodySettle_01~03` | 몸이 바닥에 살짝 닿는 소리 | 눕기, 내려놓기, 착지하기 |

짖음, 헥헥거림, 낑낑거림, 킁킁거림은 **실제 강아지 녹음**을 짧게 잘라 만든 소리입니다. 발소리와 몸이 닿는 소리만 직접 만든 효과음입니다.

같은 종류의 소리가 여러 개인 이유는 매번 똑같은 소리가 나면 로봇처럼 들리기 때문입니다. 시스템이 여러 파일 중 하나를 골라 재생 속도도 조금씩 바꿉니다.

---

## 2. 가장 쉬운 확인 방법

### 2-1. 게임 실행하기

1. Unity 위쪽의 `Play` 삼각형 버튼을 누릅니다.
2. 강아지가 있는 플레이 화면으로 들어갑니다.
3. 강아지가 걷거나 달릴 때 발소리를 들어봅니다.
4. 강아지를 쓰다듬어 헥헥거림과 기쁜 소리를 확인합니다.
5. 컨트롤러의 `B` 또는 `Y` 버튼으로 강아지를 불러 짖는 소리를 확인합니다.
6. 강아지를 들었다가 내려놓아 숨소리와 몸이 닿는 소리를 확인합니다.

기본 기능은 자동입니다. 처음 확인할 때는 Animation Event를 직접 넣거나 음원 파일을 칸에 끌어놓을 필요가 없습니다.

### 2-2. 소리가 나오는 위치

- 짖음, 헥헥거림, 낑낑거림, 킁킁 소리는 강아지의 **입**에서 나옵니다.
- 발소리는 소리를 낸 **각 발**에서 나옵니다.
- 눕거나 내려놓는 소리는 강아지의 **몸 중심**에서 나옵니다.

따라서 강아지의 왼쪽에 서면 왼쪽에서 들리고, 강아지에게서 멀어지면 소리가 작아집니다.

## 3. 자동으로 소리가 맞는 원리

중요한 코드는 다음 파일에 있습니다.

`Assets/Scripts/Audio/PetAudioController.cs`

게임을 시작하면 강아지에 `Pet Audio Controller`가 자동으로 붙습니다.

### 3-1. 발소리

시스템은 다음 네 발 뼈를 찾습니다.

- `foot_f.L`: 왼쪽 앞발
- `foot_f.R`: 오른쪽 앞발
- `foot_b.L`: 왼쪽 뒷발
- `foot_b.R`: 오른쪽 뒷발

걷기, 트롯, 달리기, 회전 애니메이션 중 실제 발이 바닥에 닿는 순간에만 소리를 냅니다.

이 방식의 장점은 애니메이션 속도를 빠르게 하거나 느리게 해도 발소리가 계속 발동작을 따라간다는 점입니다.

### 3-2. 단단한 바닥과 부드러운 바닥

기본적으로 일반 바닥에서는 `Paw_Hard` 소리가 납니다.

바닥 오브젝트나 물리 재질 이름에 다음 단어가 있으면 `Paw_Soft` 소리를 사용합니다.

- 영어: `carpet`, `rug`, `grass`, `bed`, `fabric`, `cloth`, `soft`, `cushion`, `sofa`
- 한글: `카펫`, `러그`, `잔디`, `침대`, `천`, `쿠션`, `소파`, `부드러운`

예를 들어 바닥 이름을 `LivingRoom_Carpet` 또는 `거실 카펫`으로 만들면 부드러운 발소리가 납니다.

### 3-3. 헥헥거림

자동 헥헥거림은 짧은 숨을 억지로 이어 붙이지 않고 `PantCycle`의 자연스러운 호흡 묶음을 사용합니다. `Pant_In`과 `Pant_Out`은 Animation Event로 특정 프레임에 직접 넣고 싶을 때 사용합니다.

헥헥거림은 긴 반복 음원 하나가 아닙니다. 짧은 들숨과 날숨을 번갈아 재생합니다.

다음 상황에서 자동으로 시작합니다.

- 강아지가 트롯이나 달리기를 해서 운동량이 쌓였을 때
- 플레이어가 강아지를 쓰다듬고 있을 때
- 플레이어가 강아지를 들어 올리고 있을 때

강아지가 쉬면 운동량이 천천히 줄고 헥헥거림도 멈춥니다.

### 3-4. 짖는 소리

현재 애니메이션 이름에 `Bark`가 들어가면 짖는 애니메이션으로 판단합니다.

애니메이션이 약 16% 진행됐을 때 입 위치에서 짖는 소리가 납니다. 입이 열리기 전에 너무 빨리 소리가 나지 않도록 약간 기다리는 것입니다.

### 3-5. 쓰다듬기와 내려놓기

- 쓰다듬기 시작 시 약 38% 확률로 기분 좋은 낑낑거림이 납니다.
- 강아지를 내려놓으면 약 0.5초 후 몸이 바닥에 닿는 소리가 납니다.
- 매번 소리가 나서 시끄러워지지 않도록 기쁜 소리는 확률을 사용합니다.

## 4. Unity 인스펙터에서 소리 조절하기

게임을 실행할 때는 `Pet Audio Controller`가 자동으로 생깁니다. 하지만 값을 저장하면서 계속 조절하려면 컴포넌트를 미리 추가하는 방법이 편합니다.

### 4-1. 컴포넌트 미리 추가하기

1. `Assets/Scenes/PlayScene/PlayScene.unity`를 엽니다.
2. Hierarchy에서 `Cartoon_ShibaInu_c2`를 선택합니다.
3. Inspector 아래쪽의 `Add Component` 버튼을 누릅니다.
4. `Pet Audio Controller`를 검색해 추가합니다.
5. 씬을 저장합니다.

컴포넌트를 미리 추가해도 자동 생성 코드와 충돌하지 않습니다. 이미 붙어 있으면 새로 만들지 않습니다.

### 4-2. 가장 자주 바꾸는 값

#### 자동 연결

- `발소리 자동 재생`: 네 발의 바닥 접촉으로 발소리를 재생합니다.
- `헥헥거림 자동 재생`: 달리기, 쓰다듬기, 들기에 맞춰 숨소리를 재생합니다.
- `짖음 자동 재생`: Bark 애니메이션에 맞춰 짖습니다.
- `쓰다듬기 기쁜 소리 확률`: 0이면 전혀 안 나고, 1이면 매번 납니다.

#### 발소리

- `걷기 발소리 크기`: 기본값 0.24
- `트롯 발소리 크기`: 기본값 0.32
- `달리기 발소리 크기`: 기본값 0.42
- `발소리 최소 간격`: 발소리가 너무 빠르게 겹치는 것을 막습니다. 기본값 0.075초입니다.
- `부드러운 바닥 레이어`: 이름 대신 Unity Layer로 카펫이나 잔디를 지정하고 싶을 때 사용합니다.

#### 헥헥거림

- `헥헥거림 크기`: 기본값 0.22
- `헥헥 시작 운동량`: 낮추면 조금만 달려도 헥헥거리고, 높이면 오래 달려야 합니다.
- `운동량 증가 속도`: 높을수록 달린 뒤 빨리 헥헥거립니다.
- `운동량 회복 속도`: 높을수록 멈춘 뒤 빨리 조용해집니다.
- `숨 사이 간격`: 들숨과 날숨 사이의 짧은 쉬는 시간입니다.

#### 짖음과 목소리

- `짖는 시점`: Bark 애니메이션의 어느 부분에서 소리를 낼지 정합니다. 기본값 0.16은 16% 지점입니다.
- `짖는 소리 크기`: 기본값 0.72
- `낑낑·킁킁 소리 크기`: 기본값 0.38
- `내려놓기 소리 지연`: 그립을 놓은 뒤 몸소리를 재생하기까지 기다리는 시간입니다.

#### 3D 공간 음향

- `가까운 거리`: 이 거리 안에서는 소리가 가장 또렷하게 들립니다. 기본값 0.55m입니다.
- `최대 거리`: 이 거리보다 멀어지면 거의 들리지 않습니다. 기본값 9m입니다.

처음에는 모든 볼륨을 1로 올리지 마세요. 발소리와 헥헥거림이 계속 재생되므로 짖는 소리보다 작게 두는 것이 자연스럽습니다.

## 5. Animation Event로 정확한 프레임에 소리 넣기

대부분은 자동 모드로 충분합니다. 발표용 애니메이션처럼 한 프레임까지 정확히 맞춰야 할 때만 이 방법을 사용합니다.

### 5-1. 먼저 알아둘 점

자동 재생과 Animation Event를 동시에 사용하면 같은 소리가 두 번 날 수 있습니다.

- 발소리 Event를 직접 넣을 때는 `발소리 자동 재생`을 끕니다.
- 헥헥 Event를 직접 넣을 때는 `헥헥거림 자동 재생`을 끕니다.
- Bark Event를 직접 넣을 때는 `짖음 자동 재생`을 끕니다.

### 5-2. FBX 애니메이션에 Event 넣기

1. Project 창에서 시바견 애니메이션 FBX를 선택합니다.
2. Inspector에서 `Animation` 탭을 누릅니다.
3. `Clips` 목록에서 수정할 애니메이션을 고릅니다.
4. `Events` 타임라인을 펼칩니다.
5. 소리가 나야 하는 프레임으로 재생 막대를 옮깁니다.
6. `Add Event` 또는 작은 `+` 버튼을 누릅니다.
7. Function 이름을 아래 목록에서 선택합니다.
8. Inspector 아래의 `Apply` 버튼을 누릅니다.

### 5-3. 사용할 수 있는 Event 함수

| Function 이름 | 실행되는 소리 |
| --- | --- |
| `AudioFootstepFrontLeft` | 왼쪽 앞발 |
| `AudioFootstepFrontRight` | 오른쪽 앞발 |
| `AudioFootstepBackLeft` | 왼쪽 뒷발 |
| `AudioFootstepBackRight` | 오른쪽 뒷발 |
| `AudioPantIn` | 숨 들이마시기 |
| `AudioPantOut` | 숨 내쉬기 |
| `AudioBark` | 짖기 |
| `AudioHappyWhine` | 기쁜 낑낑거림 |
| `AudioSniff` | 냄새 맡기 |
| `AudioBodySettle` | 몸이 바닥에 닿기 |

### 5-4. Event를 놓기 좋은 위치

- 발소리: 발바닥이 바닥에 처음 닿는 프레임
- 짖음: 입이 빠르게 열리기 시작하는 프레임
- 들숨: 입이 벌어지고 가슴이 커지기 시작하는 프레임
- 날숨: 가슴이 작아지고 혀가 앞으로 나오는 프레임
- 몸소리: 배나 엉덩이가 바닥 또는 침대에 닿는 프레임
- 킁킁 소리: 코를 앞으로 내미는 프레임

## 6. 내가 만든 음원으로 바꾸기

### 가장 쉬운 방법

1. 새 음원을 WAV 파일로 준비합니다.
2. 가능하면 `모노`, `44.1kHz`, `16bit`로 저장합니다.
3. 파일을 `Assets/Audio/PetAudio/Resources/PetAudio`에 넣습니다.
4. 아래 규칙에 맞춰 파일 이름을 정합니다.

예시:

- 새 짖음: `Bark_05.wav`
- 새 단단한 발소리: `Paw_Hard_07.wav`
- 새 부드러운 발소리: `Paw_Soft_07.wav`
- 새 날숨: `Pant_Out_05.wav`

게임을 다시 실행하면 같은 이름 그룹의 음원을 자동으로 찾아 사용합니다.

### 왜 모노 음원이어야 하나요?

스테레오 파일은 이미 왼쪽과 오른쪽이 정해져 있어 3D 위치 계산이 부자연스러울 수 있습니다. 한 지점에서 나오는 강아지 소리는 모노 파일을 사용하는 것이 안전합니다.

### 특정 음원만 직접 지정하기

`Pet Audio Controller`의 `원하는 음원으로 바꾸기` 구역을 펼친 뒤 원하는 WAV 파일을 배열에 끌어놓을 수도 있습니다.

이 배열이 비어 있으면 Resources 폴더의 기본 음원을 사용합니다. 하나라도 들어 있으면 해당 배열의 음원을 우선 사용합니다.

## 7. 소리가 안 날 때 확인하기

### 아무 소리도 안 들려요

1. 컴퓨터와 Quest의 음량이 0인지 확인합니다.
2. Unity Game 창 위쪽의 `Mute Audio`가 켜져 있지 않은지 확인합니다.
3. Main Camera에 `Audio Listener`가 있는지 확인합니다.
4. 강아지에 `Pet Audio Controller`가 붙어 있는지 확인합니다.
5. WAV 파일이 `Resources/PetAudio` 폴더 안에 있는지 확인합니다.
6. Unity Console에 빨간 오류가 있는지 확인합니다.

### 발소리가 안 나요

1. 걷기·트롯·달리기·회전 애니메이션인지 확인합니다.
2. 바닥에 Collider가 있는지 확인합니다.
3. `Ground Mask`가 바닥 Layer를 포함하는지 확인합니다.
4. 발이 바닥에서 너무 높다면 `Ground Probe Distance`를 조금 올립니다.
5. 발 뼈 이름이 `foot_f.L/R`, `foot_b.L/R`인지 확인합니다.

### 발소리가 두 번씩 나요

자동 발소리와 Animation Event가 동시에 켜진 경우입니다. 둘 중 하나만 사용합니다.

### 짖는 소리가 입보다 늦거나 빨라요

- 자동 모드에서는 `Bark Normalized Time` 값을 조절합니다.
- 더 정확하게 맞추려면 자동 짖음을 끄고 `AudioBark` Animation Event를 입이 열리는 프레임에 넣습니다.

### 헥헥거림이 너무 자주 나요

- `Pant Exertion Threshold`를 올립니다.
- `Exertion Rise Per Second`를 낮춥니다.
- `Exertion Recovery Per Second`를 올립니다.
- 쓰다듬기와 들기 중에는 운동량과 관계없이 헥헥거릴 수 있다는 점도 확인합니다.

### 가까이 있는데 소리가 너무 작아요

- 해당 볼륨 값을 조금 올립니다.
- `Minimum Distance`를 조금 올리면 가까운 거리에서 큰 소리가 유지되는 범위가 넓어집니다.

### 멀리 있어도 너무 크게 들려요

- `Maximum Distance`를 줄입니다.
- 발소리나 헥헥거림 볼륨을 낮춥니다.

## 8. 5분 확인표

게임을 완성하거나 APK를 만들기 전에 다음 항목을 한 번씩 확인합니다.

- [ ] 천천히 걸을 때 각 발과 발소리가 맞는다.
- [ ] 달릴 때 발소리가 걷기보다 조금 크다.
- [ ] 카펫과 일반 바닥의 소리가 다르다.
- [ ] 강아지를 부르면 입이 열릴 때 짖는다.
- [ ] 쓰다듬을 때 숨소리가 입 위치에서 들린다.
- [ ] 강아지를 들면 헥헥거리고, 내려놓으면 몸소리가 난다.
- [ ] 강아지에게서 멀어지면 소리가 작아진다.
- [ ] 같은 소리가 계속 똑같이 반복되는 느낌이 심하지 않다.
- [ ] 자동 기능과 Animation Event가 겹쳐 두 번 재생되지 않는다.
- [ ] Quest에서 10분 동안 플레이해도 소리가 끊기거나 늦게 나오지 않는다.

## 9. 개발자용: 기본 음원 다시 만들기

### 실제 강아지 목소리 다시 만들기

1. Unity 위쪽 메뉴에서 `Tools`를 누릅니다.
2. `My Little Pet`을 누릅니다.
3. `실제 강아지 음원 다시 만들기`를 누릅니다.

실제 녹음의 출처와 라이선스는 `Assets/Audio/PetAudio/SOURCES.md`에 적혀 있습니다.

### 발소리와 몸이 닿는 효과음 다시 만들기

발소리와 몸이 닿는 WAV 파일은 다음 생성기로 다시 만들 수 있습니다.

`Tools/GeneratePetAudio.py`

PowerShell 명령:

```powershell
& 'C:\Users\MBC\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' Tools\GeneratePetAudio.py
```

이 명령은 발소리와 몸이 닿는 효과음만 같은 이름으로 다시 생성합니다. 실제 강아지 목소리는 덮어쓰지 않습니다.
