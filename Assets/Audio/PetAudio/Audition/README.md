# 강아지 소리 선택실

이 폴더의 파일은 게임에서 아직 사용하지 않는 **미리듣기 후보**입니다. 마음에 드는 번호를 고르면 그 원본으로 애니메이션용 짧은 음원을 다시 만듭니다.

| 번호 | 파일 | 느낌 |
| --- | --- | --- |
| A | `Bark_A_FourCleanBarks.wav` | 짧고 또렷한 짖음 4번 |
| B | `Bark_B_SledDog.wav` | 힘 있고 거친 썰매견 짖음 |
| C | `Bark_C_SmallDogRapid.wav` | 작은 개의 빠르고 높은 짖음 |
| D | `Bark_D_ShortYelp.wav` | 짧고 가벼운 얍·깽 소리 |
| E | `Bark_E_OutdoorGroup.wav` | 야외에서 여러 개가 섞인 자연스러운 짖음 |
| F | `Bark_F_LargeDog.wav` | 낮고 묵직한 큰 개 짖음 |
